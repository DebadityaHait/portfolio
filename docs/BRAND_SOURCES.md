# Brand asset sources

Self-hosted brand snapshots. Every contribution repository has an explicit mapping; logos are keyed by repository, so repeated contributions retain the same identity. No asset requests go to third parties at runtime.

Simple Icons 16.33.0 SVG paths are CC0-1.0 and filled with their published brand color. Original multicolor assets are retained where available. GitHub avatars belong to the official project or organization account and are used as compact identity marks where the repository provides no suitable compact logo; they are not represented as project-specific logos. Brand names and marks remain the property of their respective owners; their appearance identifies contribution history and education/experience, without implying endorsement.

For several logos (Apple, Deno, MCP, Next.js and Twenty), black is the official mark color. Do not apply global monochrome filters or theme inversion. The UI should provide a light surface behind these assets.

## Refresh behavior

The Simple Icons version is pinned. Official project sources use their current default branch and avatars use their current public account image, so refreshing intentionally updates those snapshots. Review source changes before committing refreshed assets. The checked-in website does not depend on these upstream URLs.
